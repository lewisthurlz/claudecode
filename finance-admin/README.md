# Finance and admin

## What this area is for
Money in, targets and the admin system that runs the business.

## Key facts
- **Revenue:** £99/month subscriptions through Stripe. 13 active athletes is roughly £1,287/month gross before Stripe fees.
- **Current-stage target (Notion Coach Dashboard):** £2,000 MRR. The growth goal is 20 athletes, then 30+.
- **Notion is the all-in-one admin system.** The hub is the Coach Dashboard page, which holds the Athlete Dashboard, Tasks database, Net Revenue database, Notifications, Race Calendar and Business Overview.
- Any Stripe action that moves money or changes a subscription needs Lewis's approval (see AGENTS.md).

## Where to start
- Revenue questions: check Stripe (read-only) and the Notion Net Revenue database.
- Tasks: Notion → Coach Dashboard → Tasks.
