# AGENTS.md

## The business
Lewis Thurlbourne Coaching: one-to-one online running coaching, run solely by Lewis Thurlbourne (London-based runner, 2:31 marathon, 15:10 5K).
For ambitious, self-sufficient marathoners who want to hand off the mental load of self-coaching and train more effectively; the roster spans 5K to marathon.
£99/month rolling subscription through Stripe. 13 active athletes (Oct 2026).

## Standing rules
1. **Before starting work**, read the README for the area you're working in and the last few files in `logs/work-logs/`.
2. **Log every meaningful piece of work** at the end of the task in `logs/work-logs/YYYY-MM-DD.md` (today's date; create it if missing): what was done, decisions made, what's next. Newest entries at the bottom. Format in `logs/README.md`.
3. **Record lasting facts and decisions** in the README of the area they belong to, not here.
4. **Only add to AGENTS.md** what every agent needs in every session.
5. **Suggest and draft, then ask for approval.** Never do any of the following without Lewis's explicit go-ahead:
   - send or post anything externally (WhatsApp, email, Instagram, Final Surge comments, Notion pages athletes see)
   - create, change or publish athlete training in Final Surge
   - anything in Stripe that moves money or changes a subscription (charges, refunds, prices, cancellations)
   - spend money or sign up for paid tools
   - delete or overwrite anything (files, Notion pages, emails, workouts)
   - publish changes to the Squarespace website or Tally forms
   These permissions may loosen over time; Lewis will update this list when they do.
6. Write in plain British English. No emojis unless Lewis uses them.
