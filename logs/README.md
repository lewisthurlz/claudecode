# Logs

## How logging works
- One file per day in `work-logs/`, named `YYYY-MM-DD.md`. If today's file doesn't exist yet, create it.
- Add an entry at the end of every meaningful piece of work. Put the newest entry at the bottom.
- The log records what happened. Lasting facts and decisions also go into the README of the area they belong to.

## Entry format
```
## HH:MM – Short title (area)
**Done:** what was done.
**Decisions:** what was decided, and by whom.
**Next:** open items and what's waiting on Lewis.
```

## Reading the logs
Before starting work, read the last 2–3 days of logs to see what's in progress.
